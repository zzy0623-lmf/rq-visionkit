## 2. 分镜与台词

### 片头（0:00–0:15）
- **画面**：仓库首页 README / 架构图淡入，标题「RQ-VisionKit」。
- **配音**：*「睿擎 RK3506 开发板原生只有一个固定的 YOLOv3 示例。RQ-VisionKit
  补齐了从采集标注、模型转换、低代码部署到端侧推理的完整工具链，让自定义视觉模型
  不写代码就能跑起来。」*

### 步骤 1：采集（0:15–0:40）
- **画面**：M1 标注工具前端，点击「批量导入」，选择 NEU-DET 图片，进度条完成后网格显示 30 张。
- **配音**：*「第一步采集。M1 工具支持批量导入工业缺陷图片，自动建立数据集。」*

### 步骤 2：标注（0:40–1:05）
- **画面**：Canvas 标注器，拖拽画框，选择缺陷类别，切换到下一张。
- **配音**：*「第二步标注。网页画布上框出缺陷位置并标注类别，框和类别实时写回。」*

### 步骤 3：导出（1:05–1:20）
- **画面**：点击「导出数据集」，生成 YOLO 格式 zip（train/val 划分），提示下载。
- **配音**：*「第三步导出。一键导出 YOLO 训练格式，自动划分训练集和验证集。」*

### 步骤 4：训练（1:20–1:50）
- **画面**：终端运行 YOLOX 训练命令，滚动日志（**快进**），显示 best_ckpt。
- **配音**：*「第四步训练。用 YOLOX-Nano 轻量检测模型训练，这里快进展示。」*

### 步骤 5：转换（1:50–2:15）
- **画面**：终端运行 `rq-convert`，显示 onnxsim→pnnx→ncnnoptimize 流水线，输出 .param/.bin。
- **配音**：*「第五步转换。M2 工具把训练模型一键转成 NCNN 格式，自动处理
  Focus、concat 轴等算子兼容问题。」*

### 步骤 6：部署 + 推理查看（2:15–2:30）
- **画面**：部署控制台，选择模型目录，点「部署」，随后看板返回检测框叠加图 + 时延。
- **配音**：*「第六步部署推理。低代码控制台一键下发模型并 reload，端侧立即出框，
  看板显示检测结果和推理时延。本地和 SSH 下发共用同一套接口。」*

### 扩展 Demo：机械臂分拣（2:30–3:05）
- **画面**：分类识别演示——对物品图像推理，显示类别名 + 置信度。
- **配音**：*「扩展 Demo 是机械臂智能分拣，同一套工具链把分类模型部署到端侧，
  识别物品类别并给出置信度，为机械臂分拣提供识别结果。」*
- **注**：任务书要求「30 秒机械臂真机片段」，机械臂硬件与板端运行时尚未到位，
  **本段暂用 PC 仿真分类识别演示降级**，真机片段待硬件到位后补录替换（见 §4）。

### 片尾（3:05–3:20）
- **画面**：仓库地址 + Apache-2.0 许可证 + 感谢。
- **配音**：*「RQ-VisionKit 以 Apache-2.0 开源，代码、文档、性能基线全部可复现。
  谢谢观看。」*

## 3. 六步操作 checklist（录屏时照做）

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 采集 | M1 前端「批量导入」选 30 张 NEU-DET 图 | 网格显示 30 张 |
| 2 标注 | Canvas 画框 + 选类别，覆盖 30 张 | 共 76 框 |
| 3 导出 | 「导出数据集」→ YOLO zip | train 24 / val 6 |
| 4 训练 | `python scripts/train_neudet.py`（或 YOLOX tools/train.py） | best_ckpt.pth |
| 5 转换 | `python scripts/export_neudet.py` + `rq-convert` | model.opt.param/.bin |
| 6 部署推理 | 部署控制台选模型 → 部署 → 看板 | 检测框叠加 + 时延 |

> 每步界面与接口对应关系详见 [architecture.md](architecture.md) 与
> [e2e-run.md](e2e-run.md)（T2.4 端到端联调记录，含真实耗时与截图）。
