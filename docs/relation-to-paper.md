# 与在投稿论文的成果复用声明

## 复用内容

参赛者已有一篇在投稿论文，其中包含：

1. **训练好的 MobileNetV2 五分类模型**（TFLite INT8 格式）——在本项目中作为
   RQ-VisionKit 工具链的**第一个真实适配对象**（T1.6）：从训练框架重新导出 ONNX，
   经本工具链转换流水线产出 NCNN INT8 模型并在端侧运行。
2. **机械臂分拣系统**（HSV 定位 + 透视变换 + 逆运动学 + 舵机控制）——作为本项目的
   **扩展 Demo**（T2.5，时间盒 ≤4 天），演示经工具链转换部署后的模型驱动实际设备。

## 本项目的新增工作

RQ-VisionKit 的全部代码——采集标注工具（M1）、模型适配转换流水线（M2）、
低代码部署控制台（M3）、端侧推理运行时（M4）——均为本赛事期间新开发，
不包含论文已发表的软件成果。

## 边界声明

- 论文中的模型权重与算法仅作为**被适配/被部署对象**使用，用于验证工具链能力；
  工具链本身不依赖该论文的任何私有实现。
- 比赛提交材料中引用论文性能数据（如 RK3588 数据）时，会明确标注来源并说明
  与 RK3506 实测数据的差异来源（RK3506 无 NPU）。
- 论文当前处于投稿状态，如与赛事规则存在冲突，以赛事组委会裁定为准，必要时
  移除扩展 Demo 相关内容。
