# 路线图

本期（v1.0.0，比赛提交范围）聚焦「采集标注 → 模型适配转换 → 低代码部署 → 端侧推理」最小闭环。
以下功能按任务书范围红线**不在本期实现**，仅作长期规划素材。

## v1.1（赛后迭代）

- 标注质量增强：标注审核流、标注规范检查、数据集版本管理。
- 转换报告增强：量化前后逐层精度损失定位、更多模型族（分类/分割）模板。
- RK3506 板端运行时性能调优（多线程、内存复用），完善与官方 YOLOv3 示例的对照基线。

## v1.2

- 多用户权限与标注多人协同（本期范围红线项，延后）。
- 模型训练 Web 化：控制台内发起训练任务、查看曲线（本期范围红线项，延后）。
- 部署控制台批量设备管理、灰度切换与回滚。

## v2.0

- 移动端 App / 平板标注（本期范围红线项，延后）。
- 更多睿擎平台型号适配与算子清单自动跟进 NCNN 官方版本。
- 插件机制：自定义前后处理、自定义导出格式。
